Personne ayant travaillé sur le projet : BERTRAND Mathys

Lien vers le git: https://gitlab.univ-lorraine.fr/bertra362u/progavancee2024-bertrand

Compiler le projet:
  	- Télécharger le projet depuis le git.
	- Accédez au projet téléchargé grâce à la console. 
	- Une fois dedans, tapez "make" (cela compilera le projet). 
	- Une fois le projet compilé, entrez "./ddkz" et le jeu se lancera.

Une fois en jeu:
	Appuyez sur X pour démarrer une partie.

	Contrôles :
		- Z Q S D (Haut, Bas, Gauche, Droite)
		- Clic gauche (Tir de projectile)

Lorsque la vie tombe à 0:
	Cliquez avec le clic gauche sur "RETRY" Pour relancer une partie, ou "EXIT" pour quitter le jeu.
